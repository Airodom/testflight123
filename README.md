# Latihan ASAS Kelas 12

Latihan soal interaktif untuk HP: Sejarah dan Pendidikan Pancasila.

Lima jenis latihan: pilihan ganda, kartu hafalan, urutkan, menjodohkan, dan uraian.

Semua soal adalah soal latihan, bukan soal ujian.

## Mengubah soal

Soal ada di `data/sejarah.js` dan `data/pkn.js`. Ubah isinya, simpan, lalu unggah lagi.
